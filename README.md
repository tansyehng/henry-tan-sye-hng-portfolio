# Henry Tan Portfolio

A responsive personal portfolio for Henry Tan, built with plain HTML, CSS, and JavaScript.

## Preview locally

Open `index.html` in a browser. There is no build step or package installation.

## Publish with GitHub Pages

This repository is ready to publish from the `main` branch and repository root through Settings → Pages. The site is static, does not need a server or secret keys, and includes `.nojekyll` to publish the files directly.
